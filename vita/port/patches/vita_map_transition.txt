Vita map transitions: managed threads run inline on this port, so the "background" map load used to run on the
first frame of the walk-out, with the music still playing. It now runs once the screen is fully covered by the
transition. Collections only happen at that point: before the load if memory is short, and afterwards, while
the screen is still covered, when that is cheap (a small map was loaded) or memory runs low.

The collector is conservative: one stray pointer to any object of the old map kept the whole map alive
(object -> position listener -> pool -> every object), so entering a house sometimes freed nothing and the next
exit had to collect. Emptying the old manager's lists and pools limits a stray pointer to a single object.
