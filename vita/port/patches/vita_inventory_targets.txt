Vita: opening the inventory dropped the game to 30 fps. The inventory and dungeon panels are drawn into render
targets every frame, and after a resolution change both targets were sized to the whole screen (960x544) although
the panels only cover their own area. On the Vita every target pass loads and stores the whole surface, so these two
cost about as much as two extra full frames on the GPU. Each target is now the size of its panel.

The targets are only (re)created in ResolutionChanged, which runs in the update. A first version resized them
while drawing the inventory, i.e. created GXM render targets inside an open scene, and broke all rendering on the
Vita until a restart.

REPLACE

END

REPLACE
        private readonly int _vitaPanelWidth;
        private readonly int _vitaPanelHeight;

        public void ResolutionChanged()
        {
            _width = (int)System.Math.Ceiling(_vitaPanelWidth * _scale);
            _height = (int)System.Math.Ceiling(_vitaPanelHeight * _scale);
            UpdateRenderTarget();
        }
END

The panels size themselves with the overlay scale, so it has to be updated before they are resized.

            TextboxOverlay?.ResolutionChange();

            TextboxOverlay?.ResolutionChange();
            InGameHud?.ResolutionChange();
