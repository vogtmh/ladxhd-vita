Smaller live heap. With the overworld loaded the collector has to mark ~830,000 objects (~60 MB on desktop) on
every collection, which takes 0.5-1 s on the Vita; less live data makes each collection proportionally faster.

Every game object had a 32-slot component array; the highest component index is 17.

END

Every CPosition (~23,000 with the overworld loaded) carried a Dictionary for its change listeners: five objects and
~270 bytes even with a single key, which nearly all have (both object pools register under typeof(ComponentPool)).
The first listener is now stored inline, further ones in a dictionary created on demand.

REPLACE

        private PositionChanged _firstListener;
        private Dictionary<Type, PositionChanged> _moreListeners;

FILE InGame/GameObjects/Base/CObjects/CPosition.cs
FIND
            if (PositionChangedDict.ContainsKey(type))
                PositionChangedDict[type] += positionChanged;
            else
                PositionChangedDict.Add(type, positionChanged);
REPLACE
            if (_firstListenerType == type)
                _firstListener += positionChanged;
            else if (_moreListeners != null && _moreListeners.ContainsKey(type))
                _moreListeners[type] += positionChanged;
            else if (_firstListenerType == null)
            {
                _firstListenerType = type;
                _firstListener = positionChanged;
            }
            else
            {
                if (_moreListeners == null)
                    _moreListeners = new Dictionary<Type, PositionChanged>();
                _moreListeners.Add(type, positionChanged);
            }
END
