Garbage produced every frame. Collections only run during map transitions on the Vita, so everything allocated
while playing piles up until the heap limit forces a full collection (about a second). These are the remaining
per-frame allocations found by profiling the overworld and a house while standing still.

The UI copied its element lists with ToList() twice per frame, and string[].Contains (LINQ) allocated an array
wrapper and an enumerator per element: more than half of the per-frame garbage.

        private List<UiElement> VitaSnapshot(List<UiElement> first, List<UiElement> second)
        {
            _vitaDrawList.Clear();

            return _vitaDrawList;
        }

The music player allocated a new byte array for every 10 ms chunk. The port's DynamicSoundEffectInstance copies
submitted data, so a chunk's array can be reused as soon as it has been handed over.

FILE GbsPlayer/CDynamicEffectInstance.cs
FIND

REPLACE
        private int _isDisposed;

        private readonly System.Collections.Generic.List<byte[]> _vitaFreeBuffers = new System.Collections.Generic.List<byte[]>();

        public byte[] VitaRentBuffer(int size)
        {
            while (_vitaFreeBuffers.Count > 0)
            {
                var buffer = _vitaFreeBuffers[_vitaFreeBuffers.Count - 1];
                _vitaFreeBuffers.RemoveAt(_vitaFreeBuffers.Count - 1);
                if (buffer.Length >= size)
                    return buffer;
            }
            return new byte[size];
        }
END
